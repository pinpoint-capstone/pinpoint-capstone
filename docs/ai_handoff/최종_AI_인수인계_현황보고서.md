## 3. 검증된 모델 기능

**Moment-DETR**

- 체크포인트 제한적 안전 로딩 성공
- 현재 GitHub 모델 구조와 strict=True 가중치 호환 성공
- CPU에서 실제 영어 질의 Top-3 시간 구간 반환 성공
- 테스트 영상: kr_daiso_001
- 질의: a person showing a product
- Top-1: 29.1629~31.9672초 / score 0.9626
- 단일 사례 동작 검증이며 정확도 평가 결과는 아님

**Multilingual CLIP**

- 독립 모델 가중치 복구
- 모델 로딩 및 한국어 텍스트 512차원 임베딩 생성 성공
- Moment-DETR 구간 검색 통합 성능은 미검증

**MiniLM**

- Fine-tuning 모델 및 데이터 보관 확인
- 과거 전체 텍스트 검색 평가 결과 확보
- 현재 환경의 재학습·재평가 재현성은 별도 검증 필요
- 텍스트 검색 개선을 영상 구간 검색 개선으로 해석하면 안 됨
