## 15. Moment-DETR 체크포인트 실제 로딩 검증

검증 기준:

- GitHub 커밋: `14b3eb9f6fca4eef2df258d860e32bd23ca13da9`
- 체크포인트: `03_학습모델_체크포인트/02_Korean_Video_Test/AI_Backup/scratch_clip_align_best_ORIGINAL.ckpt`
- 검증 환경: Python / PyTorch 2.11.0+cpu
- 검증 결과: 모델 생성 및 strict=True 가중치 로딩 성공
- 실제 영상 구간 추론: 아직 미검증

### 15.1 체크포인트 구성

확인된 항목:

- `model`: 가중치 OrderedDict, 98개 항목
- `opt`: argparse.Namespace 학습 설정
- `optimizer`: 학습 시점 Optimizer 상태
- `lr_scheduler`: 학습 시점 Scheduler 상태
- `epoch`: 159

주요 설정:

| 설정 | 값 |
|---|---|
| v_feat_dim | 514 |
| t_feat_dim | 512 |
| num_queries | 10 |
| contrastive_align_loss | True |
| contrastive_hdim | 64 |
| span_loss_type | l1 |
| n_input_proj | 2 |

### 15.2 실제 검증에 성공한 모델 로딩 코드

아래 코드는 Google Colab에서 GitHub 저장소를
`/content/pinpoint-capstone-ai`에 Clone한 상태를 기준으로 한다.

```python
from pathlib import Path
import argparse
import sys
import torch

REPO = Path("/content/pinpoint-capstone-ai")
HANDOFF = Path("/content/drive/MyDrive/pinpoint_capstone/05_AI_인수인계(2)")

VENDOR = REPO / "ai/vendor/moment_detr"
CKPT = HANDOFF / "03_학습모델_체크포인트/02_Korean_Video_Test/AI_Backup/scratch_clip_align_best_ORIGINAL.ckpt"

if not VENDOR.is_dir() or not CKPT.is_file():
    raise FileNotFoundError("GitHub 저장소 또는 체크포인트 경로 확인 필요")

if str(VENDOR) not in sys.path:
    sys.path.insert(0, str(VENDOR))

from moment_detr.model import (
    build_transformer,
    build_position_encoding,
    MomentDETR
)

# 체크포인트의 argparse.Namespace만 제한적으로 허용
# 출처가 신뢰되는 체크포인트에 대해서만 수행
with torch.serialization.safe_globals([argparse.Namespace]):
    checkpoint = torch.load(
        CKPT,
        map_location="cpu",
        weights_only=True
    )

opt = checkpoint["opt"]

transformer = build_transformer(opt)
position_embedding, txt_position_embedding = build_position_encoding(opt)

model = MomentDETR(
    transformer,
    position_embedding,
    txt_position_embedding,
    txt_dim=opt.t_feat_dim,
    vid_dim=opt.v_feat_dim,
    num_queries=opt.num_queries,
    input_dropout=opt.input_dropout,
    aux_loss=opt.aux_loss,
    contrastive_align_loss=opt.contrastive_align_loss,
    contrastive_hdim=opt.contrastive_hdim,
    span_loss_type=opt.span_loss_type,
    use_txt_pos=opt.use_txt_pos,
    n_input_proj=opt.n_input_proj,
)

model.load_state_dict(checkpoint["model"], strict=True)
model.to("cpu")
model.eval()

print("Moment-DETR 가중치 로딩 완료")
print("파라미터 수:", sum(p.numel() for p in model.parameters()))
```

47단계 검증 결과:
- 모델 파라미터: 4,278,217개
- 누락된 가중치 키: 0개
- 예상하지 못한 가중치 키: 0개

### 15.3 기존 GitHub 추론 코드와의 차이

현재 GitHub의 `get_model()`은
`models/moment_detr/scratch_clip_align_best.ckpt`를 참조한다.

반면 인수인계 모델은 위 `CKPT` 경로에 있다.

또한 GitHub의 `build_inference_model()` 내부에서는
`torch.load(weights_only=False)`가 사용된다.

따라서 보안 및 재현성을 위해 위에서 검증한
제한적 안전 로딩 절차를 우선 참고한다.

경로를 해결하지 않은 채 기존 `get_model()`을 호출하면
체크포인트를 찾지 못할 수 있다.

이 예시는 모델 객체 생성 및 가중치 로딩까지만 검증됐다.
영상 특징, 질의 특징, 자막을 입력한 전체 추론은
별도로 테스트해야 한다.

### 실행 과정에서 확인한 주의사항

1. `ffmpeg-python`, `ftfy` 패키지가 없어 최초 import에 실패했고,
   해당 패키지를 설치한 뒤 진행했다.
2. CLIP `ViT-B/32` 가중치 약 354MB가 실행 중 다운로드됐다.
   따라서 인터넷이 없는 새 환경에서 바로 실행될지는 미검증이다.
3. 기존 GitHub `build_inference_model()`은
   `torch.load(weights_only=False)`를 사용한다.
   이번 검증에서는 이를 호출하지 않고, 15절의 제한적 안전 로딩
   방식으로 모델을 생성해 **메모리에서만**
   `get_model`을 교체했다.
4. GitHub 소스, 체크포인트, 영상 특징 파일은 수정하지 않았다.
5. 실제 구간 반환에는 성공했지만 Ground Truth와
   비교하지 않았으므로 정확도를 검증한 결과는 아니다.
6. 본 검증은 영어 질의 1개에 한정된다.
